# RetailSystem POS Bar — releases

Este repositorio solo guarda los instaladores y las actualizaciones de **RetailSystem POS Bar** (VIP BAR).
El código está en un repositorio privado aparte.

- **Instalar en una PC nueva:** en [Releases](../../releases/latest) descarga `RetailSystem-pos-bar-win-Setup.exe` y ejecútalo.
- **Actualizaciones:** la app las busca sola aquí cuando entra un administrador, y pregunta antes de reiniciar.

Las versiones se publican con `vpk upload github` (ver `RELEASE.md` en el repositorio del código).
